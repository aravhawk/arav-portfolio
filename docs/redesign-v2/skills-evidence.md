# Skills used

Enumerated `~/.agents/skills`, `~/.claude/skills` (same 24 skills in both, plus a `synced` folder) and `~/.codex/skills` (empty). The repo also ships `.claude/skills/frontend-design`. Impeccable was not used. Nothing was installed or modified.

| Skill | Path | How it shaped the build |
| --- | --- | --- |
| ui-ux-pro-max (required) | `~/.claude/skills/ui-ux-pro-max` | Ran `search.py --design-system` (variance 9, motion 9, density 2). Took its pattern, "scroll-triggered storytelling": keep DOM reading order complete, show a progress indicator, render every chapter in its final readable state under reduced motion. That is why the story has a progress bar and countdown, and why the static version is the same DOM. Its Inter and brutalism suggestions were not used. Its checklist drove contrast, focus rings, 44px targets and the 390/768/1024/1440 overflow check. |
| landing-page-design (required) | `~/.claude/skills/landing-page-design` | One idea per screen and one primary action per beat (a single link). `text-wrap: balance` on headlines. No invented facts. Motion rule kept: transform, opacity and clip-path only, custom curves, reduced motion honoured. Its B11 "tagline reveal" became the finale line. Where it conflicts with the brief (Geist or Manrope only, flat backgrounds, 680px hero, FAQ and CTA sections), the brief wins: this is a portrait, not a conversion page. |
| design-taste-frontend (taste-skill 2.5.1, required) | `~/.claude/skills/design-taste-frontend` | Its house rules that fit were kept: no captions explaining a visual, every visual renders at every width, no violet anywhere, real facts only, scenes and shader work reserved for a technical subject, one dealt "moment" per section. Its gate (`gate.mjs`) was not armed: its one-section-per-screen and static-kit rules contradict the scroll film the brief asks for, which the previous build already documented. Its copy rules (plain words, a noun in every heading, verb plus object on links) shaped the copy. |
| emil-design-eng | `~/.claude/skills/emil-design-eng` | Curves: `cubic-bezier(0.23, 1, 0.32, 1)` for entrances and `cubic-bezier(0.77, 0, 0.175, 1)` for on-screen moves. No `transition: all`, no `scale(0)`, `:active` scale 0.97 on pressables, hover gated behind `(hover: hover) and (pointer: fine)`, exits faster than entrances (180ms out, 600 to 900ms in). |
| animate | `~/.claude/skills/animate` | The gate "should this animate at all": the index rows and filter chips do not animate on use, only on hover. Search results swap instantly. Story beats are once-per-visit, so they get the long reveals. |
| choreograph | `~/.claude/skills/choreograph` | Each beat is cast: headline is the lead (scanner reveal), kicker, line and link are support (short rise, 60 to 520ms later), callouts are decoration (fade only). One entrance per container on the sheets. Exits leave together. |
| animation-performance | `~/.claude/skills/animation-performance` | No React state on the frame path: the scroll loop writes to refs and to the engine. No inherited CSS variables animated per frame. Bloom at reduced resolution, DPR capped, reflection target at 0.85 scale (0.6 on phones). Measured 60fps in Chrome on Metal. |
| apple-design | `~/.claude/skills/apple-design` | The Merlin drag: 1:1 while held, velocity carried into a spin that decays, pointer capture, idle motion resumes after a pause. Translucent sheet over the world for the index and blog. Tracking tightens as type grows. |
| mobile-native | `~/.claude/skills/mobile-native` | `svh` units, `viewport-fit=cover` plus safe-area padding on nav and HUD, tap highlight off, 16px search input, `touch-action: manipulation`, `pan-y` on the drag pad, `overscroll-behavior` on the chip scroller, theme colour set. |
| frontend-design | `.claude/skills/frontend-design` (repo) | Commit to one bold direction and one memorable thing (a name the size of a hangar, built by a swarm). Distinctive type instead of Inter or Space Grotesk. |
| review-animations, improve-animations, find-animation-opportunities, remove-animations, break-ui, gestures, animation-vocabulary | `~/.claude/skills/*` | Read for their checklists during review. Applied: "Never ship" table from review-animations (all clear), worst-case names in the index (long repo names wrap with `overflow-wrap: anywhere`), one removal (the block wipe was replaced by a lighter scanner reveal). |
| Not relevant | animate-expo, ask-sonner, cinetic, write-swift, security-audit, pick-ui-library, prototype, find-skills | Native, video, Swift, security or component-picking skills. Not used. |
