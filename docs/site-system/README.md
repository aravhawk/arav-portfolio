# Site system: the maintainer pack

For anyone (person or agent) who adds, restores, retires or edits a
section of this site. The aim: a new section inherits the site's
transitions, light, materials and frame budget without anyone
redesigning the whole.

| Read | For |
| --- | --- |
| [architecture.md](architecture.md) | What the site is made of: the scroll timeline, the scene, how a station is put together, the render loop, shaders and materials |
| [motion.md](motion.md) | The motion system: one clock, easing, springs, durations, how words and transitions are built |
| [light-and-materials.md](light-and-materials.md) | The day and the night, the one ice, water, snow, air, and the surfaces of the DOM |
| [performance.md](performance.md) | The budget and how to measure it on the owner's display |
| [copy.md](copy.md) | How the site speaks, and what may appear on it |
| [blog.md](blog.md) | The blog's pages, its rules, and the seam between its UI and where posts come from |
| [recipes.md](recipes.md) | Step by step: add, retire or restore a station, a home section, an inner page |
| [consistency-checklist.md](consistency-checklist.md) | The whole-site pass every change must clear, and the critics' PASS criteria |
| [pitfalls.md](pitfalls.md) | What has gone wrong before |

## Status of this pack

The pack is written as the build proceeds. Each file says at its top
what is **as built** and what is **planned** (with the task that lands
it). Do not trust a planned line as fact: check the code.

- As built today: the typed flight registry, the timeline, the camera's moves, the words' steps,
  the first paint, the light's hours, shared ice, solid UI surfaces, the tests.
- Planned: the motion
  tokens in one module, the performance gate with the owner's
  profile, and a proof run in which a fresh helper adds a throwaway
  section from this pack alone.

Change log of the pack itself: see the end of each file.
