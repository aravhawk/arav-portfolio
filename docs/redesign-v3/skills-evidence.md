# Skills evidence

Skills were listed from `~/.agents/skills`, `~/.claude/skills` (symlinks into `~/.agents/skills`) and `~/.codex/skills` (empty). Nothing was installed or modified. Impeccable was not used.

| Skill | Path | Decisions it shaped |
|---|---|---|
| ui-ux-pro-max | `~/.agents/skills/ui-ux-pro-max` | The priority order used for gates: accessibility first (4.5:1 text on glass, focus rings never removed, 44px touch targets), then touch, performance (reserve space, CLS near 0), then style. Hover is never the only way to reach anything; every hover preview on /work also has a link. |
| landing-page-design | `~/.agents/skills/landing-page-design` | One typeface family (Archivo) plus a mono only for numeric readouts (Geist Mono). No italics, no weight above 800. Floating translucent nav pill, full-height mobile menu with 60ms link stagger capped at 400ms. Complete state set (hover, active, focus, loading, empty, error). The word-by-word tagline reveal (B11) became the closing statement beat. Skip link, branded 404, current page marked in nav. Its flat-background and Tailwind-scale rules are overridden by the brief (authored WebGL world, display type at viewport scale). |
| design-taste-frontend (tasteskill 2.5.1) | `~/.agents/skills/design-taste-frontend` | The "never" list: no violet, no fade-in on every section, no captions under visuals, no invented figures, no copying a reference's signature effect. One section per screen: every home beat is one pinned screen. Copy rules: nouns in headings, a hard fact on the first screen (the four readouts). Its kit, dealer and gate target company pages built from its starter; this build is a bespoke WebGL portfolio specified by the brief, so the kit was not mounted and its gate was not run. That is a deliberate deviation, recorded here. |
| emil-design-eng | `~/.agents/skills/emil-design-eng` | Custom curves only (`--ease-out: cubic-bezier(0.23,1,0.32,1)`, `--ease-in-out: cubic-bezier(0.77,0,0.175,1)`, `--ease-drawer: cubic-bezier(0.32,0.72,0,1)`). Press feedback `scale(0.97)` at 140ms. Never `scale(0)`, never `transition: all`, hover motion gated behind `(hover: hover) and (pointer: fine)`. Blur used to bridge crossfades. |
| animate | `~/.agents/skills/animate` | The build sequence per animation: frequency gate, purpose, cheapest tool. Archive search and filter results do not animate (high frequency, keyboard driven). UI durations under 300ms; the long durations are reserved for the intro and beat choreography. |
| choreograph | `~/.agents/skills/choreograph` | One entrance per container: a glass pane arrives as one object, its contents do not stagger separately. Lead, support, decoration casting per beat (the giant word leads, the pane supports, readouts fade). Non-uniform staggers. Exits are simultaneous and shorter. Reduced motion collapses choreography instead of shortening it. |
| apple-design | `~/.agents/skills/apple-design` | Springs specified as response and damping ratio; critically damped by default, bounce only after a gesture with momentum (drag release of the drop, the switch flip). Velocity handoff from drag to spring. Rubber-banding on drag. Glass rules: material weight encodes hierarchy, never light glass on light glass, bright top edge as the light-catching rim, materialize (blur plus scale) instead of plain fade, `prefers-reduced-transparency` and `prefers-contrast` variants. |
| animation-performance | `~/.agents/skills/animation-performance` | Transform and opacity only in the DOM. No React state per frame: scroll, pointer and springs write straight to `style` or WebGL uniforms. No inherited CSS variables driven per frame on big subtrees (rim light variables are set on the pane itself). Animated blur kept under 20px. |
| gestures | `~/.agents/skills/gestures` | Dragging the drop: 1:1 while the pointer is down with pointer capture, spring seeded with release velocity afterwards, interruptible mid-flight. |
| frontend-design (repo local, `.agents/skills/frontend-design`) | in repo | Commit to one bold direction; distinctive display face instead of a default UI font. |

Not used: `prototype`, `pick-ui-library`, `cinetic`, `mobile-native` (read for the 100dvh, tap-highlight and safe-area notes, which are applied), `break-ui` (its long-string checks were applied by hand to the archive rows).
